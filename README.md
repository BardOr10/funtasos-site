# Funtasos Studios — GitHub Pages site

האתר מוכן להעלאה ל-GitHub Pages.

## קבצים
- `index.html` — האתר הראשי, דו-לשוני עברית/אנגלית.
- `thanks.html` — עמוד תודה לאחר שליחת טופס.
- `assets/` — לוגו ופוסטר ShadowLight.
- `CNAME` — מגדיר את `funtasos.com` כדומיין המותאם אישית.
- `.nojekyll` — מונע עיבוד Jekyll מיותר.

## טופס יצירת קשר
הטופס משתמש ב-FormSubmit ללא תשלום ושולח אל `info@funtasos.com`.
בפעם הראשונה שממלאים את הטופס, FormSubmit שולח מייל אימות לכתובת הזו.
צריך לפתוח את מייל האימות ולאשר פעם אחת. לאחר מכן הטופס יעבוד רגיל.

## GitHub Pages — תקציר
1. צור Repository חדש ב-GitHub.
2. העלה אליו את כל הקבצים שבתיקייה הזו.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. תחת Custom domain הזן `funtasos.com`.
5. ב-GoDaddy יש לעדכן את רשומות האתר לפי ההוראות ש-GitHub יציג.
   אל תמחק את רשומות ה-MX/TXT של המייל.
